01

上游版本门禁

原来

每日只要 upstream/main 有新提交就合并，普通提交也会触发冲突与人工处理。

现在

定时触发先解析上游 main 上最新 v* 版本 tag；该 tag 已在 HEAD 时短路，不合并普通提交。

原因 把自动同步收敛到上游版本边界，降低每日冲突频率。
