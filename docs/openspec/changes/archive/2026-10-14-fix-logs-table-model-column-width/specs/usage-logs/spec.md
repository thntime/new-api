## ADDED Requirements

### Requirement: 重试次数列不扩大表格总列宽预算

「重试次数」列在管理员视角下 MUST NOT 扩大使用日志表格的总列宽预算；新增该列所占用的宽度 MUST 从「渠道」「用户」「令牌」三列中收回，使管理员（common）视图的总列宽不超过新增该列之前的值。模型列 MUST 保持新增该列之前的宽度占比，其徽标与尾部指示图标 MUST 处于同一行。

#### Scenario: 管理员视角总列宽不增加

- **WHEN** 管理员打开使用日志（common 类）列表
- **THEN** 所有列 `size` 之和等于「重试次数」列新增之前的总列宽（1570）
- **AND** 「渠道」「用户」「令牌」三列宽度之和等于各自原宽度之和减去「重试次数」列宽度

#### Scenario: 模型列图标与模型名同行

- **WHEN** 某条日志的模型名较长，且该模型存在实际模型或响应模型异常
- **THEN** 模型徽标与其尾部指示图标（Route 图标或异常警示）显示在同一行，不换行到第二行
