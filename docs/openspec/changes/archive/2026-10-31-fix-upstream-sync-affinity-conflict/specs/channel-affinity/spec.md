# Spec Delta

## Purpose

补充「亲和命中后的重试层起点」契约：亲和渠道消耗一次尝试但不占用优先级层，因此常规降序重试必须从最高优先级层开始；跨分组切换后偏移失效；`descent` 模式的环形层序不受影响。本 delta 来自上游 `fcc241cdf fix: start affinity fallback at the highest channel priority (#8078)` 与本地 `descent`/兜底定制的合并，仅把既有语义写明确，不改变既有验收场景。

## ADDED Requirements

### Requirement: 亲和命中后的重试层起点

渠道亲和性命中并直接使用原渠道时，该次尝试 MUST 被视为已消耗一次重试机会，但 MUST NOT 占用任何优先级层。随后进入常规候选池重试时，层索引 MUST 减去亲和消耗的一次尝试，使首次重试从候选池最高优先级层开始。

分组切换后，亲和偏移 MUST 归零：新分组 MUST 从该分组最高优先级层开始，MUST NOT 继承上一分组的偏移。

`descent` 会话模式的层下标为「锚点层 + 重试次数」，MUST NOT 应用该偏移，否则会重选原层。

#### Scenario: prefer 模式亲和命中后首次重试从最高层开始

- **WHEN** 会话模式为 `prefer`，亲和命中优先级为 3 的渠道 X，候选池最高优先级层为 4，且 X 返回可重试错误
- **THEN** 首次重试使用优先级 4 的渠道，而不是优先级 3 的渠道

#### Scenario: 跨分组切换后重新从新组最高层开始

- **WHEN** 令牌分组为 `auto` 且启用跨分组重试，亲和命中后已在原分组完成重试并切换到下一分组
- **THEN** 新分组从该分组最高优先级层开始，不因亲和偏移跳到第二层

#### Scenario: descent 模式不应用亲和偏移

- **WHEN** 会话模式为 `descent`，亲和命中位于锚点层的渠道，且该渠道返回可重试错误
- **THEN** 后续尝试按锚点层逐层向下推进，不因亲和偏移重选锚点层
