01

后端导出与导入

原来

渠道配置只能逐个手工重建，跨实例迁移没有安全通道。

现在

选中渠道用密码加密导出为 .nacx；导入时输入同一密码才创建，id 自增且严格保持文件顺序。

原因 支持实例迁移、备份恢复和批量复制，同时避免密码错误或文件被篡改时落库。

查看文件和关键代码 4
新增controller/channel_export.go
ExportChannels / ImportChannels：scrypt + AES-256-GCM 信封、DTO 白名单、逐条校验、BatchInsertChannels 整批回滚
修改model/channel.go
GetChannelsByIdsOrdered：按请求 ids 保序查询，缺失 id 报错
修改router/channel-router.go
POST /api/channel/export、/import，权限 ChannelSensitiveWrite
修改controller/audit.go
channel.export / channel.import 审计模板，只记录 count
02

前端入口与弹窗

原来

渠道页没有导入导出入口。

现在

批量操作栏可导出选中渠道；「更多操作」可导入 .nacx；弹窗处理密码、文件选择、下载和错误翻译。

原因 让管理员在现有渠道列表里完成迁移，不需要手工拼请求。

新增web/src/features/channels/components/dialogs/import-channels-dialog.tsx
读取文件文本、提交 password/content、内层 error_key/error_params 翻译、刷新列表
修改web/src/features/channels/components/data-table-bulk-actions.tsx
导出按钮：无选中或无敏感写权限时不可用
修改web/src/features/channels/components/channels-primary-buttons.tsx
